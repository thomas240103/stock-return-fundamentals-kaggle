# Data Directory

Do not commit Kaggle data to this repository.

Download the official competition files from:

https://www.kaggle.com/competitions/predict-1-year-us-stock-returns-from-fundamentals

Place the files here:

```text
data/raw/train.csv
data/raw/test.csv
data/raw/sample_submission.csv
```

The folders are kept in git with `.gitkeep`, but raw and processed data files are ignored by `.gitignore`.
